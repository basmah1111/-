مشروع تحليل المشاعر (LSTM.ipynb)

​الوصف: بناء نموذج تعلم عميق (Deep Learning) 
لتصنيف مشاعر مراجعات الأفلام باستخدام شبكات LSTM.

​المميزات:

​معالجة النصوص وتحويلها إلى تسلسلات رقمية (Tokenization & Padding).

​تصنيف المراجعات إلى 5 مستويات (من سلبي جداً إلى إيجابي جداً).

​بناء هيكل عصبي يحتوي على طبقات Embedding و LSTM و Dropout.

​المكتبات المستخدمة: keras, tensorflow, pandas, numpy.
